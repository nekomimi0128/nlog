# 📻 NLog (Ham Radio Log & QSL Card Maker)

アマチュア無線の交信記録（ログ）の管理と、QSLカードのレイアウト・印刷までをブラウザ上でシームレスに行うためのWebアプリケーションです。

---

## ✨ 特徴

* **📝 サクッとログ記録**  
  モードや周波数、RSレポート、QTH、D-STARのレピータ情報を手軽に入力・保存。
* **🎨 QSLカード自動レイアウト**  
  記録した交信データをもとに、QSLカードのプレビューをリアルタイムで生成。
* **🖱️ 直感的な操作**  
  テキストのドラッグ＆ドロップによる位置合わせや、縦横切替に対応。
* **🌐 ブラウザ完結**  
  特別なインストール不要。Webサイトにアクセスするだけですぐに使えます。

---

## 🚀 使い方

1. **アクセスする**: [ここにGitHub PagesのURLを貼ってください] にアクセスしてください。
2. **記録する**: 左側のフォームから交信データを入力し、「ログを保存」ボタンをクリックします。
3. **デザイン調整**: 右側のプレビューでQSLカードのデザインを確認・調整します。
4. **印刷する**: ブラウザの印刷ダイアログ（用紙サイズ：ハガキ、余白：なし/最小）を開き、そのままプリンターで出力します。
